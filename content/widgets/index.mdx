# Welcome to Ligature Docs

Ligature provides stateless, edge-rendered SVGs for your GitHub READMEs. You can simply copy a Markdown URL to use our widgets.

## Installation

You don't need to install anything! Just browse the available widgets, customize them to your liking, and copy the Markdown snippet into your README.

```md
[![Ligature Stats](https://ligature.dev/api/github?user=octocat)](https://ligature.dev)
```
