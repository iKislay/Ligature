# GitHub Trends

The **GitHub Trends** widgets provide detailed insights into your language usage, repository contributions, and more over various time periods.

## Preview

Here is an example of what the language contribution widget looks like for `iKislay`:

```md
![GitHub Trends](https://api.githubtrends.io/user/svg/iKislay/langs?theme=classic&time_range=one_year)
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `username` | - | Your GitHub username or User ID |
| `card` | `langs` | Type of card: `langs` or `repos` |
| `theme` | `classic` | Visual theme (e.g., `classic`, `dark`) |
| `time_range` | `one_year` | Range: `one_month`, `six_months`, `one_year`, `all_time` |

## Example Markdown

```md
[![GitHub Trends](https://api.githubtrends.io/user/svg/iKislay/langs?time_range=all_time&theme=dark)](https://githubtrends.io)
```

<Callout>
  **Note:** Depending on the API's requirements, generating your personal stats might require you to authenticate once via the GitHub Trends platform so your data can be fetched and cached.
</Callout>
