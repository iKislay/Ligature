# GitHub Summary Cards

Generate detailed SVG summary cards showing your GitHub statistics in five different visual styles.

<WidgetPreview type="summary-stats" />

## Card Types

The summary cards API provides five distinct card styles:

| Card | Description | Endpoint Card Parameter |
|------|-------------|------------------------|
| **Stats** | Total stars, commits, PRs, issues, and contributed repos | `card=stats` |
| **Profile Details** | User info with contribution area chart | `card=profile-details` |
| **Repo Languages** | Donut chart showing languages by repository count | `card=repos-per-language` |
| **Commit Languages** | Donut chart showing languages by commit count | `card=most-commit-language` |
| **Productive Time** | Bar chart showing commits per hour of day | `card=productive-time` |

## Endpoint

```
GET /api/github-summary?user=<username>&theme=<theme>&card=<card_type>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `theme` | `default` | Color theme (see below) |
| `card` | `stats` | Card type identifier |

## Available Themes

default, dark, dracula, github, github_dark, tokyonight, radical, gruvbox, nord_bright, nord_dark, solarized, solarized_dark, monokai, vue, zenburn

## Example

```md
![GitHub Stats Summary](https://ligaturemd.netlify.app/api/github-summary?user=octocat&theme=dark&card=stats)
```
