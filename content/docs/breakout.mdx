# Breakout

Smash through rows of bricks using a paddle and ball, rendered as an SVG on your GitHub contribution grid.

<WidgetPreview type="breakout" />

## Endpoint

```
GET /api/games?user=<username>&game=breakout&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `game` | `breakout` | Game identifier |
| `theme` | `github` | Color theme |

## Example

```md
[![Breakout](https://ligaturemd.netlify.app/api/games?user=octocat&game=breakout)](https://ligaturemd.netlify.app)
```

## Gameplay

- Control the paddle with AI
- Break all bricks to win
- Each brick color represents a different point value
- The ball speed increases as bricks are cleared
