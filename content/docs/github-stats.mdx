# GitHub Stats

Display your commits, pull requests, issues, and star count in a single lightweight card.

<WidgetPreview type="github-stats" />

## Endpoint

```
GET /api/github?user=<username>&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `iKislay` | GitHub username |
| `theme` | `geist` | Color theme (see [Themes](/docs/themes)) |

## Example

```md
[![Ligature Stats](https://ligatures.netlify.app/api/github?user=iKislay&theme=geist)](https://ligatures.netlify.app)
```

## Available Themes

| Theme | Style |
|-------|-------|
| `geist` | Clean, modern light |
| `geist_dark` | Dark mode variant |
| `cyberpunk` | Neon glow, dark terminal |
| `minimal` | Sparse, neutral, high contrast |
| `retro` | Solarized-inspired warm tones |

## Custom Theme

```md
[![Ligature Stats](https://ligatures.netlify.app/api/github?user=iKislay&theme=cyberpunk)](https://ligatures.netlify.app)
```

## Rendering

This endpoint generates **SVGs dynamically**. It supports all themes from the classic `github-readme-stats` library and produces sharp, scalable vector graphics!
