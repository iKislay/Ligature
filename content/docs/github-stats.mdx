# GitHub Stats

Display your commits, pull requests, issues, and star count in a single lightweight card.

## Endpoint

```
GET /api/github?user=<username>&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `iKislay` | GitHub username |
| `theme` | `radical` | Color theme (see [Themes](/docs/themes)) |

## Rendering

This endpoint generates **SVGs dynamically**. It supports all themes from the classic `github-readme-stats` library and produces sharp, scalable vector graphics!
