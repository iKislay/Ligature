# GitHub Profile Overview

Showcase your GitHub contributions and top repositories in a single, beautiful widget that fetches live data directly from GitHub APIs.

<WidgetPreview type="github-profile" />

## Usage

Simply copy the markdown snippet below and paste it into your `README.md` file. The widget will automatically update with your live GitHub data!

```markdown
[![GitHub Profile Overview](https://ligatures.netlify.app/api/github/profile?user=your-username&theme=geist_dark)](https://github.com/your-username)
```

## Parameters

You can customize the widget by adding the following parameters to the URL:

| Parameter | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `user` | `string` | `gautamkmahato` | Your GitHub username. |
| `theme` | `string` | `geist` | The color theme of the widget. Try `cyberpunk`, `retro`, `geist_dark`, or `minimal`. |
