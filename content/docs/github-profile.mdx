# GitHub Profile Overview

Showcase your GitHub contributions and top repositories in a single card. Just copy, paste, and you're done.

<WidgetPreview type="github-profile" />

## Endpoint

```
GET /api/github/profile?user=<username>&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `gautamkmahato` | GitHub username |
| `theme` | `geist` | Color theme |

## Available Themes

| Theme | Style |
|-------|-------|
| `geist` | Clean, modern light |
| `geist_dark` | Dark mode variant |
| `cyberpunk` | Neon glow, dark terminal |
| `minimal` | Sparse, neutral, high contrast |
| `retro` | Solarized-inspired warm tones |

## Example

Copy this into your README.md:

```md
[![GitHub Profile Overview](https://ligaturemd.netlify.app/api/github/profile?user=gautamkmahato&theme=geist)](https://github.com/gautamkmahato)
```
