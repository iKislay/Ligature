# Puzzle Bobble

Aim, shoot, and match three or more bubbles of the same colour to clear them in this classic puzzle game rendered over your GitHub contributions.

<WidgetPreview type="puzzle-bobble" />

## Endpoint

```
GET /api/games?user=<username>&game=puzzle-bobble&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `game` | `puzzle-bobble` | Game identifier |
| `theme` | `geist` | Color theme

## Available Themes

| Theme | Style |
|-------|-------|
| `geist` | Clean, modern light |
| `geist_dark` | Dark mode variant |
| `cyberpunk` | Neon glow, dark terminal |
| `minimal` | Sparse, neutral, high contrast |
| `retro` | Solarized-inspired warm tones |

## Example

```md
[![Puzzle Bobble](https://ligatures.netlify.app/api/games?user=octocat&game=puzzle-bobble)](https://ligatures.netlify.app)
```

## Gameplay

- Aim your shot using the trajectory guide
- Match 3+ same-colour bubbles to pop them
- Clear connected bubbles to drop remaining ones
- Keep the playfield clear to survive
