# GitHub 3D Contributions

The **3D Contributions** widget generates a beautiful isometric 3D view of your GitHub contribution graph.

## Endpoint

```
GET /api/github-3d-contrib?user=<username>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `torvalds` | GitHub username |
