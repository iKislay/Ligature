# Quick Start

Getting a widget on your profile takes two steps.

## 1. Pick a Widget

Choose from the available widgets in the sidebar. Each widget has its own API endpoint.

## 2. Copy the Markdown

Every widget page shows you the exact Markdown snippet to use. For example:

```md
[![GitHub Stats](https://ligature.dev/api/github?user=your-username)](https://ligature.dev)
```

Replace `your-username` with your GitHub or GitLab username.

## 3. Paste into Your README

Open your profile repository, edit `README.md`, and paste the snippet. Commit and push.

## Customizing Themes

Add `&theme=` to the URL to change the appearance:

```md
[![GitHub Stats](https://ligature.dev/api/github?user=octocat&theme=github-dark)](https://ligature.dev)
```

See the [Themes](/docs/themes) page for available options.
