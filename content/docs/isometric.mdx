# Isometric Contribution Graph

Turn your contribution grid into a 3D isometric visualization.

<WidgetPreview type="isometric" />

## Endpoint

```
GET /api/isometric?user=<username>&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `theme` | `github` | Widget theme |

## Themes

The isometric graph supports all standard Ligature themes plus these exclusive variants:

- `north` — Northern Hemisphere seasonal colors
- `south` — Southern Hemisphere seasonal colors
- `night` — Dark blue nighttime palette
- `halloween` — Orange and purple spooky colors
- `gitblock` — Monochrome block theme
