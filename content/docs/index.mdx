# Welcome to Ligature

Ligature lets you generate beautiful, customizable SVG widgets for your GitHub and GitLab profile READMEs. No login required — just enter your username and go.

## How It Works

1. Browse the available widgets
2. Pick a username and theme
3. Copy the Markdown snippet
4. Paste it into your README

That's it. Your stats are fetched fresh on every request and rendered as a PNG or SVG image.

## Features

- **Zero config** — no database, no login required
- **Always up to date** — widgets fetch fresh data on every load
- **Arcade Games** — playable retro games overlaid on your contribution graph
- **Multiple Themes** — dark, light, seasonal, and custom palettes
- **GitHub + GitLab** — support for both platforms
- **Open Source** — MIT licensed, contributions welcome

## Quick Example

Copy this into your `README.md`:

```md
[![Ligature Stats](https://ligaturemd.netlify.app/api/github?user=octocat)](https://ligaturemd.netlify.app)
```

<Callout>
  All widgets follow the same pattern: an `<img>` or Markdown link pointing to a Ligature API endpoint. No authentication needed.
</Callout>
