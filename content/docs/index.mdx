# Welcome to Ligature

Ligature lets you generate beautiful, customizable SVG widgets for your GitHub and GitLab profile READMEs. Every widget is rendered at the edge — no servers, no state, no maintenance.

## How It Works

1. Browse the available widgets
2. Pick a username and theme
3. Copy the Markdown snippet
4. Paste it into your README

That's it. The SVG is rendered on every request by **Next.js Edge Runtime**, so your stats are always up to date.

## Features

- **Stateless** — no database, no state management
- **Edge-rendered** — fast responses from CDN edges worldwide
- **Arcade Games** — playable retro games overlaid on your contribution graph
- **Multiple Themes** — dark, light, seasonal, and custom palettes
- **GitHub + GitLab** — support for both platforms
- **Open Source** — MIT licensed, contributions welcome

## Quick Example

Copy this into your `README.md`:

```md
[![Ligature Stats](https://ligature.dev/api/github?user=octocat)](https://ligature.dev)
```

<Callout>
  All widgets follow the same pattern: a `<img>` or Markdown link pointing to a Ligature API endpoint.
</Callout>
