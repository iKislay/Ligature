# GitHub Skyline

The **GitHub Skyline** widget generates a 3D-printable STL file of your GitHub contribution graph. It uses the official `gh-skyline` CLI extension to analyze your yearly contributions and render them as a 3D model.

## Adding to your README

Since GitHub natively supports rendering STL files, you can embed your generated STL directly into your README. Once you have generated the STL using the CLI, upload it to your repository and simply link to it.

```md
Check out my [GitHub Skyline 3D Contribution Graph](iKislay-github-skyline.stl)!
```

*(Note: In GitHub READMEs, clicking on an STL file link opens an interactive 3D viewer, allowing visitors to spin and zoom in on your contribution graph!)*
