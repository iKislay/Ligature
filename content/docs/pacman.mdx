# Pac-Man

Navigate Pac-Man through the maze, eat pellets, and avoid ghosts — all rendered as an SVG overlay on your contribution grid.

<WidgetPreview type="pacman" />

## Endpoint

```
GET /api/games?user=<username>&game=pacman&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `game` | `pacman` | Game identifier |
| `theme` | `geist` | Color theme |

## Available Themes

| Theme | Style |
|-------|-------|
| `geist` | Clean, modern light |
| `geist_dark` | Dark mode variant |
| `cyberpunk` | Neon glow, dark terminal |
| `minimal` | Sparse, neutral, high contrast |
| `retro` | Solarized-inspired warm tones |

## Player Styles

The Pac-Man widget supports multiple AI play styles:

- `opportunistic` — default, chases nearest pellet
- `aggressive` — prioritises power pellets and ghosts
- `scatter` — avoids ghosts, prefers safe routes

## Example

```md
[![Pac-Man](https://ligaturemd.netlify.app/api/games?user=octocat&game=pacman)](https://ligaturemd.netlify.app)
```

## Ghosts

Four classic ghosts with distinct personalities:

- **Blinky** — chases directly
- **Pinky** — ambushes ahead of Pac-Man
- **Inky** — uses Blinky's position for strategy
- **Clyde** — alternates between chase and scatter
