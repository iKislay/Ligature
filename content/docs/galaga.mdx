# Galaga

Pilot your starship through waves of alien formations in this classic arcade shooter overlaid on your GitHub contributions.

## Endpoint

```
GET /api/games?user=<username>&game=galaga&theme=<theme>
```

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `user` | `octocat` | GitHub username |
| `game` | `galaga` | Game identifier |
| `theme` | `github` | Color theme |

## Example

```md
[![Galaga](https://ligature.dev/api/games?user=octocat&game=galaga)](https://ligature.dev)
```

## Features

- Formation waves of alien enemies
- Dive-bomb attack patterns
- Power-ups from defeated enemies
- Score multiplier for consecutive kills
