# Themes

Every Ligature widget supports a `theme` parameter to match your README's visual style.

## Usage

Add `&theme=<name>` to any widget URL:

```md
[![GitHub Stats](https://ligatures.netlify.app/api/github?user=octocat&theme=geist_dark)](https://ligatures.netlify.app)
```

## Available Themes

| Theme | Preview | Style |
|-------|---------|-------|
| `geist` | Light | Clean, modern — the default |
| `geist_dark` | Dark | Dark variant for dim environments |
| `cyberpunk` | Dark | Neon glow, green-on-black terminal |
| `minimal` | Light | Sparse, neutral, high contrast |
| `retro` | Light | Solarized-inspired warm tones |

## Theme Properties

Each theme defines:

| Property | Description |
|----------|-------------|
| **Background** | Card fill color |
| **Text** | Primary text color |
| **Primary** | Accent / highlight color |
| **Secondary** | Muted / label color |
| **Border** | Card outline color |
| **Typography** | Font family |
| **Effects** | Optional scanlines, grain, or glow |

## Custom Themes

To create a custom theme, open a PR on [GitHub](https://github.com/iKislay/Ligature) adding your theme to `src/lib/themes.ts`.
